# E-Commerce Sales Analysis

A data analysis project focused on applying core data analyst skills, including data cleaning, SQL analysis, exploratory data analysis, and visualization.

## About the Project

This project uses an online sales dataset containing **240 transactions across 9 columns** to explore business performance and identify trends in revenue, products, and regions.

The objective was to simulate a real-world junior data analyst workflow — starting with data cleaning and exploration, followed by SQL-based KPI analysis and visualization of key findings.

## Tools & Technologies

- **Python (Pandas, Matplotlib, Seaborn)** — Data cleaning, EDA, and visualization
- **MySQL** — Business queries and KPI analysis
- **Excel** — Summary reporting and presentation of results

## Business Questions

The analysis was designed to answer the following questions:

- Which product category contributes the most revenue?
- How does revenue change from month to month?
- Which region generates the highest share of sales?
- What are the key business KPIs, including total revenue, orders, and AOV?

## Key Metrics

- **Total Revenue:** $80,567.85
- **Total Orders:** 240
- **Average Order Value:** $335.70
- **Total Units Sold:** 518
- **Product Categories:** 6
- **Regions:** 3

## Key Takeaways

This project provided hands-on experience with common data analyst workflows, including date handling, data cleaning, groupby-based aggregations, SQL querying, and translating analytical results into business insights.

One of the main challenges was correctly formatting and sorting the date data to ensure the monthly revenue trend was displayed in the right chronological order.
